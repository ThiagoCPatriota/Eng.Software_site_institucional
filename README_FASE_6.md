# FASE 6 — Estrutura e Corpo Docente

## O que foi implementado
- Nova identidade do cabeçalho com o escudo do curso e wordmark textual.
- Atualização do rodapé com a mesma identidade visual.
- Criação das páginas `estrutura.html` e `docentes.html`.
- Inclusão dos estilos específicos:
  - `assets/css/pages/estrutura.css`
  - `assets/css/pages/docentes.css`
- Atualização do menu principal para incluir Estrutura e Docentes.
- Ajuste do JavaScript para destacar o item ativo do menu por página.
- Uso de placeholders institucionais para docentes, sem inventar fotos pessoais.

## Sequência prática de teste
1. Abrir `index.html` e verificar o novo cabeçalho com o escudo e o nome IFPE Engenharia de Software.
2. Clicar em `Estrutura` no menu e conferir a página `estrutura.html`.
3. Clicar em `Docentes` no menu e conferir a página `docentes.html`.
4. Testar a navegação em celular, abrindo o menu mobile.
5. Verificar se os links de Lattes demonstrativos estão visíveis e marcados como em atualização.
6. Conferir o destaque do item ativo no menu em cada página.
7. Testar o botão de voltar ao topo no rodapé.

## Observações
- Os dados de docentes foram deixados como modelos institucionais. Quando os nomes e links reais forem enviados, basta substituir o conteúdo dos cards.
- A página de contato ainda continua apontando para a seção de contato da home, até a fase específica dessa área.
