# README_FASE_10_26

## Fase 10.26 — Footer institucional

Esta microfase reformula o rodapé do site para um visual mais institucional, inspirado na organização visual de portais públicos, com fundo escuro, navegação em colunas e área de identidade no canto inferior.

## Arquivos alterados
- Todos os arquivos `.html` da raiz do projeto
- `assets/css/components/footer.css`
- `README_FASE_10_26.md`

## O que mudou
- O rodapé deixou de ser uma estrutura simples em poucas colunas.
- A navegação foi reorganizada em grupos:
  - Curso
  - Vida acadêmica
  - Estrutura
  - Atendimento
- Foi adicionada uma marca textual `IFPE` no topo do footer.
- Foi criada uma área de canais institucionais em modo demonstrativo.
- Foi criada uma área de identidade com o escudo do curso e texto institucional.
- O botão de voltar ao topo foi preservado.
- O footer foi aplicado em todas as páginas principais.

## Sequência prática de teste
1. Substituir os arquivos deste ZIP no projeto.
2. Abrir `index.html`.
3. Rolar até o footer.
4. Conferir se ele está mais profissional e organizado em colunas.
5. Testar links do footer.
6. Clicar no botão de voltar ao topo.
7. Abrir outras páginas, como `sobre.html`, `projetos.html`, `contato.html` e `faq.html`, para confirmar que o footer aparece igual.
8. Testar no celular.

## Observação
Os canais institucionais e contatos continuam em modo demonstrativo, pois ainda dependem de dados oficiais reais.
